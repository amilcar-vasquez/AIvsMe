# AI vs Me: World Cup Predictor Frontend

## Stack
- SvelteKit
- API-first communication with Django backend

## Quick Start
1. `npm install`
2. `npm run dev`

Set backend URL if needed:
- `VITE_API_BASE_URL=http://localhost:8000/api`

## Routes
- `/` Home dashboard
- `/matches/[id]` Match detail and prediction duel
- `/results` Results and live scoreboard summary

## Design Source of Truth
The design system artifacts are stored in `frontend/design` and mirrored from the Stitch exports.
